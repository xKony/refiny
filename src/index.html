Welcome to Refiny

  1. Connect a provider

    The API key is read from an environment variable — it is never written to config.toml. 

    setx REFINY_API_KEY "sk-..."

    Restart Refiny after setting it. Local endpoints such as Ollama or LM Studio usually need no key; edit config.toml to point at one.

  2. Polish anything

    Select text in any app and press Ctrl+Alt+P. The polished text replaces the selection.

  3. Leave it running

    Closing this window keeps Refiny in the tray. Use the tray menu to reopen it or quit.
