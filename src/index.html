Provider

Any endpoint with the POST /chat/completions shape works. Point it at a local server and the text never leaves this machine.

Hotkey

The global shortcut that starts a polish action. It applies the moment you save.

Use CommandOrControl for Ctrl on Windows and Linux, Cmd on macOS. A combination another application already owns is rejected, and your current hotkey keeps working.

Prompts

An empty prompt uses the built-in default. The preservation list is appended to whichever prompt is active.

Named presets

Switch between these from the tray menu.

Playground

The same pipeline the hotkey uses, without touching your selection.
